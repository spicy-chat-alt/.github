A practical overview of browser-based character tools that let you start a thread and return to it later. Independent page. Limits and prices change.

### Quick comparison

| Aspect | Free tier | Paid tier |
| --- | --- | --- |
| Messages | Limited count | Higher or unlimited |
| Characters | Restricted | More available |
| Images | Limited or locked | Unlocked |
| Voice | Limited or locked | Available |
| Memory | Shorter | Improved |
| Filters | Stricter | Fewer on most plans |

The free tier is short by design. Paid raises limits and unlocks media tools.

---

### Typical steps

1. Open the browser tool.  
2. Choose a ready character or open the builder.  
3. Set name, appearance and short background if building.  
4. Send test messages.  
5. Stay in the thread for continuity.  
6. Upgrade when free messages end.

### Before you pay

- Check exact free message count.  
- Confirm what paid unlocks (chat volume, images, voice).  
- Note the image generation meter.  
- Read the renewal price.  
- Verify the cancel path.  
- Avoid real personal data in chat.
